# Revamp

Create or redesign a website, build a web app, and keep improving it by chatting with Revamp. Describe the result you want in ordinary language; Revamp starts a project you can preview and refine in the same conversation.

## Connect

Install this bundle and connect your Revamp account when prompted. It uses Revamp’s hosted service at `https://app.revamp.dev/mcp`. The bundle contains no account credentials and runs no local server.

## Try it

- “Create a modern website for my law firm with practice areas, attorney profiles, and consultation requests.”
- “Redesign my website at [public URL] to make it easier to request a consultation.”
- “Build a client portal where customers can sign in and see project updates.”
- “Show my recent Revamp projects.”

You can start a project without opening Studio. Ask Revamp to check progress and show the latest available preview, then request changes to the same project. A preview is not a published website.

Learn more at [revamp.dev](https://revamp.dev/). For help, visit [Revamp support](https://revamp.dev/support/).
